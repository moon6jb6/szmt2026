## 1. 一句话定位

1937 年 10 月，四行仓库里一个识字的通城兵，用五夜时间决定：**哪些名字能被带出去**。

玩家不是枪手，是记录者。核心动作不是射击，是「带什么过河」。

---

## 2. 为什么是这个题

四行仓库题材已被电影《八佰》充分消费，直接拍战斗必然同质化（创新性 25 分里明确写了"避免简单模仿、素材拼接和同质化表达"）。本作的差异点只有一个，但足够硬：

**四百二十个人，最后只有八十七个名字被找回来。**

- 1937 年 10 月 26 日—11 月 1 日，88 师 524 团一营据守四行仓库，对外称"八百壮士"，实际 400 余人（《辞海》作 452 名，通城方面考证约 420 人）。
- 其中湖北通城籍 200 人以上。1947 年通城县参议会编《通城县抗战史料》，收《通城县参加上海四行孤军四十九壮士姓名一览表》。
- 截至 2015 年，多方寻访查实姓名仅 87 人，最后一位周福其 2005 年 11 月离世；仍有百余人姓名待查。

这不是虚构的悲情，是**正在进行的、未完成的寻找**。游戏把"记名字"变成可玩的动作，把"名字丢失"变成玩家要承担的结果。

**红线（硬约束，写进代码注释）**

1. 不做杀敌计数、不做"战斗评分"、不把苦难做成奖励。
2. 结局不绑定死亡人数；只改变"哪些记忆被留下"。
3. 真实人物（谢晋元、杨惠敏）只以有出处的引文/事实出现，不虚构其台词与心理。
4. 虚构主角在首次出场与结局页永久标注"复合型虚构角色"。
5. 每条史实结论必须有"史料卡"，写明来源；未核实的内容不得进入游戏正文。

## 5. 叙事结构

### 5.1 框架

- **序幕 · 1947 年冬，湖北通城**：县参议会要编《抗战史料》，瘸腿文书陈望生被派去"把四行孤军的通城弟兄名字造册"。他手里只有半本血浸的旧册子。
- **主体 · 1937 年 10 月 26—31 日，上海**：倒叙五夜。
- **尾声 · 1947 / 2015**：名册交上去，四十九个名字；多年后，八十七个。最后一行："还有一百多个名字，没有人知道。"

主角陈望生：虚构，通城籍，19 岁，保安大队文书，识字，随部队整编补充进 524 团一营。职责是被谢晋元指定"把名字记下来"。首次出场即标注"复合型虚构角色"。

### 5.2 五夜（每夜一次"带什么过河"）

| 夜 | 日期 | 事件锚点 | 玩家抉择 | 可得记忆载体 |
|---|---|---|---|---|
| 一 | 10/26 | 进驻仓库，清点人数 | 名册放身上还是留仓库 | 名册页 |
| 二 | 10/27 | 日军逼近，伤兵增多 | 带名册／伤兵名单／家书 | 名册页·家书 |
| 三 | 10/28 | 升旗 | 带旗／带名册／带照片 | 旗·照片 |
| 四 | 10/29 | 中外记者到南岸 | 名单给记者／给同乡会／留下 | 口述·名册页 |
| 五 | 10/30—31 | 撤退令 | 带一个人／带名册／留下断后 | 口信·名册页 |

每夜固定结构：场景（2.5D）→ 情境文本 → 2—3 个抉择 → 结果文本 → 史料卡（可展开）。

### 5.3 时长预算

- 单周目：13 个场景，约 25—35 分钟。
- 全结局：6 条线，约 100—120 分钟。
- 正文字数：约 1.2 万—1.6 万字（含结局）。

## 6. 记忆账本与六个结局

### 6.1 账本

```ts
type Ledger = {
  roster: number      // 名册页 0-5
  letters: number     // 家书 0-5
  flag: 0 | 1         // 旗
  photo: 0 | 1        // 照片
  testimony: number   // 口述 0-5
  message: 0 | 1      // 口信
  returned: boolean   // 最后一夜是否回仓库
}
```

### 6.2 六个结局（按主导载体判定，同分看最后一夜选择）

| # | 结局 | 主导 | 情绪落点 | 史实钩子 |
|---|---|---|---|---|
| 1 | 《名册》 | roster | 名字进了县志，你的不在上面 | 1947 年四十九壮士名表 |
| 2 | 《家书》 | letters | 十二封信送到，收信人哭，你不敢说他们怎么死的 | 孤军营家书 |
| 3 | 《旗》 | flag | 旗的尺寸和针脚被记下，四十年后照着重缝 | 升旗与杨惠敏 |
| 4 | 《口述》 | testimony | 你活到 1980 年代，讲了六小时，讲到第八十七个名字时忘了自己 | 87 人查实 |
| 5 | 《照片》 | photo | 合影背面一行字，十一个人认出九个 | 租界记者影像 |
| 6 | 《口信》 | message | 你只带出一句话，它传了四代 | 通城寻访 |

结局不排名、不评分，只有"哪一种记忆被留下"。全部结局都标注同一句：**"还有一百多个名字，没有人知道。"**

## 7. 视觉：单图伪 2.5D

- 每个场景一张 1024×576 生成图（SDXL + Lightning，4 步）。
- 分层不靠切图，靠**同图三尺度复制**：远景 1.0、中景 1.06、近景 1.14，各自不同位移系数 + 轻微模糊，鼠标/陀螺仪驱动透视位移。
- 前景叠 canvas 粒子：雨、灰、火星、纸屑。
- 转场：交叉溶解 + 镜头缓推；关键抉择时压暗四周。
- 调色：旗帜红 #A32B2B、铁锈 #7A3E2E、沙金 #C8A063、烟黑 #16130F、纸白 #EDE6D8。
- 字体：思源宋体（标题）+ 思源黑体（正文），本地打包，不引外链字体。

## 8. 技术架构

```
src/
├─ main.tsx
├─ App.tsx                 // 屏幕路由 + 状态
├─ game/
│  ├─ types.ts             // Scene / Choice / Ledger / Ending
│  ├─ engine.ts            // 纯函数：applyChoice / resolveEnding / save / load
│  ├─ content/
│  │  ├─ prologue.ts
│  │  ├─ night1..5.ts
│  │  ├─ epilogue.ts
│  │  ├─ endings.ts
│  │  └─ sources.ts        // 史料卡
│  └─ components/
│     ├─ Stage.tsx         // 2.5D 视差舞台
│     ├─ Particles.tsx
│     ├─ Dialogue.tsx
│     ├─ ChoiceList.tsx
│     ├─ SourceCard.tsx
│     └─ EndingCard.tsx
└─ styles.css
```

- 无后端；localStorage 存档（`names-ledger-v1`）。
- 路由用状态机，不引 react-router。
- 无障碍：Tab 可达、Enter 确认、`prefers-reduced-motion` 关闭视差、正文可缩放。
- 性能：图片 `loading="lazy"` + 预取下一场景；单页 JS 目标 < 250KB gzip。

## 12. 风险

| 风险 | 应对 |
|---|---|
| 同质化（《八佰》） | 不做战斗，做记录；宣传语只打"名字" |
| "不当娱乐化"审查 | 无杀戮计分、无失败惩罚、结局不排优劣 |
| 史料不足 | 只写已核内容；未核的用留白，不编 |
| 时间不够 | 先保五夜 + 六结局可跑通，再谈美术 |
| 生成图风格漂移 | 固定 seed 池 + 固定 prompt 模板 + 统一 negative |
