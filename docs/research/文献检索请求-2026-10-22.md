> 项目：《把名字留下来》——1937 年四行仓库保卫战与「八百壮士」名册的交互叙事作品。史料卡注册表在 `src/game/content/sources.ts` 与 `sources.auto.ts`。

## 一、我要你做什么

按 JSON 里的 20 条 `req-*` 逐条找**可定位的原文**，交回一个 JSON。**不是写综述、不是给结论、不是替我判断哪一说对**——我要的是「哪本书哪一页 / 哪个链接哪一段，原话是什么」。每条最终只会用上一个字段：**逐字原文 + 可定位出处**。

找到后会进两处：游戏里场景页脚的**史料卡**（点开显示原句+出处），和正文的**引文**。所以：拿到不能定位的东西 = 没拿到。

## 二、硬规则（违反一条，该条作废）

1. **不许编造**：书名、作者、出版社、年份、页码、档号、日期、数字、URL，一个都不许猜。不确定就写 `not_found`。
2. **必须可定位**：`书名+章节+页码` 或 `URL+发布日期+段落位置`，二者必居其一。
3. **原句必须逐字**：删节用「……」，不许意译后加引号，不许把两段话拼成一句。
4. **说法不一就并列**：状态填 `ambiguous`，`quote` 里把各版本并列，**不要替我选一个**。
5. **找不到就报找不到**：`not_found` + `note` 写清查了哪些库/哪些关键词、为什么没有。这份报告本身也是成果。
6. **禁止作为最终出处**：百科聚合条目（只可当线索）、自媒体/公众号/短视频文案、论坛帖、AI 生成摘要、影视剧情。
7. **数字必须带口径**：谁统计的、统计范围（在库/撤入租界/入营/伤亡）写清，不同口径不可合并。
8. **图片只作参考**：找到照片请给「出处+授权状态」，不要下载、不要贴图，我不用受版权保护的图。

## 三、输出格式（只输出一个 JSON）

```json
{
  "filled": [
    {
      "req_id": "req-03",
      "status": "found",
      "fact": "一句话事实，可直接写进正文",
      "quote": "逐字原句（≤120 字）",
      "source": {
        "type": "book",
        "work": "书名 / 文章标题 / 档案名",
        "author": "作者或编者",
        "publisher": "出版社 / 媒体 / 馆藏机构",
        "year": 2010,
        "url": "https://…（网络来源必填）",
        "locator": "第 X 章《…》，p.123 / 第 06 版第 3 段 / 全宗号-案卷号"
      },
      "confidence": "high",
      "note": "版本差异、存疑点、转引关系"
    }
  ]
}
```

- `status`：`found` / `ambiguous` / `not_found`。**20 条一条都不能省**，找不到也要出一条。
- `req_id` 用 JSON 里的 id（req-01 … req-20）。
- 其中 **7 条是「原来就有槽位号」的旧账**，请在该条 `note` 里带上原槽位号，方便脚本直接并回：`req-01`→`G-02`、`req-02`→`A-08`、`req-04`→`B-11`、`req-08`→`G-01`、`req-09`→`G-03`、`req-16`→`G-04`、`req-17`→`G-05`。
- 引用超过 120 字的部分请截在 120 字内，其余放 `note`。

## 四、拿到之后我怎么用（你不用管，但决定了我收什么）

- **旧槽位 7 条**：并入 `docs/deliverables/史料收集回填.json` → 跑 `node tools/import-collected-sources.mjs` → 自动生成 `sources.auto.ts` 的卡。所以这 7 条必须严格按上表 `req_id`↔槽位号对应。
- **其余 13 条**：人工在 `sources.ts` 新建卡（`s-` 前缀）或补 `auto-*` 卡。判定条件只有一条：**有 `excerpt`（可引原句）+ `locator`（页码/章节/URL+日期）才能把 `status` 写成 `verified`**；缺任何一个，卡必须留在 `needed` / `pending`，只登记「还缺哪本书的哪一章」。
- 卡填好后再把卡 id 加进对应场景的 `sources: []`，页脚自动出现，不用改 UI。
