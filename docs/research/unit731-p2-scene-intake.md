## 首个可互动示例：建议范围

建议将首个 P3 样例限定为“**旧址外围—无文字设施辨认**”。玩家观察经审核的空间线索卡，并把“地点 / 设施类别 / 时间范围 / 来源”拖入证据图谱；不扮演施害者、不进入实验操作、不把受害者经历作为谜题奖励。

此处的“旧址外围”仅是设计书已确定的章节节点名称，不暗示任何尚未审核的建筑布局、门牌、内部设施或事件经过。

## 克制表现取景（仅表现层）

首版先固定为低辨识度、不可反推具体史实的纪念性环境草图。待审核来源确认后，再把通过核验的时代、地貌与建筑形制加入受控参数。

- 前景：雨后土路、未经标识的旧围栏材质、落叶、低矮草地；不出现门牌、文字或符号。
- 中景：低矮、抽象化的砖石/混凝土外墙轮廓与树影；不复制具体建筑立面，不给出可识别入口。
- 后景：阴天、低饱和雾气与远处树线，留出右下角互动界面安全区。
- 镜头：16:9 横幅，平视或略低机位，环境观察距离；无人物、无受害者、无施害者、无行为复演。
- 交互：热点只打开经审核的“来源卡”和“待连接的证据类别卡”；在资料未通过前，界面显示“资料审核中”，不展示解释性结论。

## 资产使用规则

1. 未确认来源与版权/使用条件前，不下载馆藏图片、新闻图片、历史摄影或地图到项目目录。
2. 生成图不应临摹单张历史照片、展陈图或建筑立面；审核通过后新增具体形制时，必须记录其来源与审核意见。
3. 每个通过审核的场景包都要保存 `provenance.json`：模型与版本、完整 PromptSpec、生成时间、输出哈希、引用 `factId`、审核日期和审核人。
4. `hotspots.json` 只能引用已审核的来源卡 ID；找不到来源时，热点不可启用。
5. 完整表现与克制表现均不得包含人体实验操作、受害者肖像作为收集物、猎奇音效、可循环的伤害画面，或把错误连接转化为刺激性失败反馈。
6. 固定图和审核文字分别版本化：替换图片不能修改史实字段；替换史实字段必须重新审核证据图谱规则。
