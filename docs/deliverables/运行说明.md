# 运行与使用说明

## 一、运行环境

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge / Firefox 最近两年版本 |
| 分辨率 | 桌面 1280×720 及以上；兼容平板与手机 |
| 网络 | **无需联网**。无外部字体、无 CDN、无后端请求 |
| 其他 | 需要启用 JavaScript 与 localStorage（存档用） |

## 二、评审期快速启动（推荐）

### 方式 A：本地静态服务器（最稳，推荐）

构建产物用了 ES Module，**必须通过 HTTP 起服务**（直接双击 `index.html` 会被浏览器的 file:// 安全策略拦成白屏，这不是作品问题）。

在 `01_作品及成果文件/` 目录下执行任意一种：

```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve -l 8080

# PHP
php -S 127.0.0.1:8080
```

浏览器打开 <http://127.0.0.1:8080/>。

> 打包说明：构建已改成相对路径（`base: './'`），所以整个 `01_作品及成果文件/` 目录放在任意子目录下都行，在父目录起服务也能正常访问。

### 方式 B：源码开发模式

```bash
npm install
npm run dev        # 开发预览
npm run build      # 产出 dist/
npm run preview    # 预览构建产物
```

## 三、操作方式

| 操作 | 鼠标 / 触摸 | 键盘 |
|---|---|---|
| 选择 | 点击选项 | `1` `2` `3` `4` |
| 继续 | 点击「继续」 | `Enter` 或 `空格` |
| 展开史料卡 | 点击页脚卡片 | Tab 聚焦后 Enter |
| 存档 | 自动 | 自动 |
| 删除存档 | 菜单「从头开始」会覆盖 | — |

- 存档位置：浏览器 `localStorage`，键名 `names-ledger-v1`。
- 结局图鉴：键名 `names-endings-v1`。
- 清除方式：浏览器设置里清除该站点数据即可。

## 四、内容与时长

- 正文：113,138 字（严格口径），140 个场景，9 个结局（6 个主结局 + 3 个合成结局）
- 单周目：约 2—3 小时；可分段阅读，存档自动
- 全部内容（九结局 + 10 篇人物志 + 15 篇「后来」+ 76 张史料卡）：约 6 小时
- 无失败状态，可随时关闭，下次从上次的位置继续

## 九、常见问题

**Q：打开后是白屏？**
A：用方式 A 起一个本地服务器（`file://` 双击会被 ES Module 的安全策略拦下）；或确认浏览器未禁用 JavaScript。

**Q：结局页为什么先黑一下？**
A：那是结局的「终极画面」（约 6 秒，Canvas 绘制）。点画面任意位置就能跳过，直接进结局正文。结局正文下面有「重看结局画面」按钮。系统开了「减少动态效果」时只显示最终帧。

**Q：九个结局怎么解锁？**
A：尾声只会列出你这一周目真正带出来的记忆。六个主结局对应六种载体；如果同时带走两样（名册+口述 / 家书+照片 / 旗样+口信），会额外出现合成结局「档案 / 遗物 / 口耳」。图鉴里 9 格，未解锁的会显示解锁条件。

**Q：没有声音？**
A：默认静音，点右下角「声音」才开，状态会记住。这一版只有 28 条环境音与动作音（4.88 MB），没有人声配音，也没有音乐。这是取舍，不是坏了。

**Q：背景图是渐变不是照片？**
A：如果拿到的是「无图版」，说明插画素材没有随包分发。渐变占位版也能完整玩完，叙事与结局不受影响。完整包里才有 `public/art/` 下的场景插画。

**Q：如何只看结局？**
A：菜单 →「结局一览」，已解锁的结局会显示标题与副标题。
