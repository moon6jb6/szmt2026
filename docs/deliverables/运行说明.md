# 运行与使用说明

## 一、运行环境

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge / Firefox 最近两年版本 |
| 分辨率 | 桌面 1280×720 及以上；兼容平板与手机 |
| 网络 | **无需联网**。无外部字体、无 CDN、无后端请求 |
| 其他 | 需要启用 JavaScript 与 localStorage（存档用） |

## 二、评审期快速启动（推荐）

### 方式 A：直接打开构建产物

1. 解压参赛打包文件。
2. 进入 `01_作品及成果文件/`，双击 `index.html`。

> 注意：部分浏览器对 `file://` 协议下的模块脚本有限制。若打开后白屏，请改用方式 B。

### 方式 B：本地静态服务器（最稳）

在 `01_作品及成果文件/` 目录下执行任意一种：

```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve -l 8080

# PHP
php -S 127.0.0.1:8080
```

浏览器打开 <http://127.0.0.1:8080/>。

### 方式 C：源码开发模式

```bash
npm install
npm run dev        # 开发预览
npm run build      # 产出 dist/
npm run preview    # 预览构建产物
```

## 三、操作方式

| 操作 | 鼠标 / 触摸 | 键盘 |
|---|---|---|
| 选择 | 点击选项 | `1` `2` `3` `4` |
| 继续 | 点击「继续」 | `Enter` 或 `空格` |
| 展开史料卡 | 点击页脚卡片 | Tab 聚焦后 Enter |
| 存档 | 自动 | 自动 |
| 删除存档 | 菜单「从头开始」会覆盖 | — |

- 存档位置：浏览器 `localStorage`，键名 `names-ledger-v1`。
- 结局图鉴：键名 `names-endings-v1`。
- 清除方式：浏览器设置里清除该站点数据即可。

## 四、内容与时长

- 正文：110,020 字（严格口径），140 个场景，6 个结局
- 单周目：约 2—3 小时；可分段阅读，存档自动
- 全部内容（六结局 + 10 篇人物志 + 15 篇「后来」+ 76 张史料卡）：约 6 小时
- 无失败状态，可随时关闭，下次从上次的位置继续

| 入口 | 内容 | 说明 |
|---|---|---|

## 五、无障碍

- 全流程键盘可达，焦点有可见描边
- 支持 `prefers-reduced-motion`：系统开启「减少动态效果」后，视差与粒子自动降级
- 正文字号可随浏览器缩放（`Ctrl/Cmd + +/-`）
- 无闪烁、无高频动画

## 六、内容提示

本作涉及战争与死亡，但不表现血腥场面，不出现真实人物肖像。虚构主角陈望生在首次出场处标注为「复合型虚构角色」。全部史实条目在游戏内「史料库」中列出来源。

## 七、常见问题

**Q：打开后是白屏？**
A：用方式 B 起一个本地服务器；或确认浏览器未禁用 JavaScript。

**Q：没有声音？**
A：本版暂未加入音乐与音效，属明确的取舍，不是故障。

**Q：背景图是渐变不是照片？**
A：若拿到的是「无图版」，说明插画素材未随包分发；以渐变占位版亦可完整游玩，叙事与结局不受影响。完整包内含 `public/art/` 下的场景插画。

**Q：如何只看结局？**
A：菜单 →「结局一览」，已解锁的结局会显示标题与副标题。
