## 一、必下（三本，都能搜到）

### 1. 陈立人《八百壮士：中国孤军营上海抗战纪实》

- 副标题也叫「电影《八佰》英雄原型」
- 出版社：团结出版社
- ISBN：9787802149298
- 字数：23.9 万字，22 章
- 在哪搜：**微信读书 / 掌阅**（我已在掌阅书目里看到这本书）
- 为什么是主书：从四行仓库坚守写到孤军营、谢晋元遇刺，正好覆盖游戏的五夜 + 结局。
- **我要的具体位置：**
  | 章 | 补什么 |
  |---|---|
  | 第 2 章《孤堡》 | 五夜逐日战况（10/26—31），对应第一至五夜 |
  | 第 3 章《血醒租借地》 | 升旗与送旗经过，对应第三夜 |
  | 第 6 章《孤军营不是田横岛》 | 缴械后的处境，对应第五夜结尾 |
  | 第 18 章《英雄倒在黎明》 | 谢晋元遇刺，对应结局 |

### 2. 余子道、张云、吴海勇、韩洪泉《上海抗日战争史》

- 出版社：上海人民出版社
- 出版年：2025（上海书展新书）
- 在哪搜：微信读书 / 京东读书 / 各书店，新书容易找
- 为什么：最新、最权威的上海抗战全景，用来校核淞沪会战的时间线、四行仓库撤退后的上海态势。
- **我要的具体位置：** 淞沪会战相关章节里，关于「四行仓库」「闸北撤退」的段落（2—3 处即可）。

### 3. 戴胜德、谭元亨《挥剑四行：谢晋元传》

- 丛书：「十一五」国家重点图书出版规划客家研究文丛
- 在哪搜：**微信读书**（我已看到书目页）
- 为什么：人物线。谢晋元为什么留在仓库、他怎么带兵、他最后几年怎么过。
- **我要的具体位置：** 四行仓库章节里，关于**点名、登记、部属姓名**或带兵细节的段落。

## 四、拿到后怎么给我（最省事）

这三本都在阅读平台上，所以最方便的是：

1. **微信读书/掌阅里划线复制原句**，连章节名一起发我，例如：
   > 《八百壮士》第 2 章《孤堡》：「……」+ 章节位置
2. 或者**截图**关键页（能看到章节名/页码即可）。
3. 或者把整本书的 PDF/EPUB 发我，我自己定位。

我只需要 **6 个位置**，不需要整本。拿到后我会：

- 把对应 `sources.ts` 里的 `needed` 卡填上 `excerpt` + `locator`，状态改成 `verified`；
- 把卡片 id 加进目标场景的 `sources`，游戏页脚自动出现这张卡，点开就是原句 + 出处；
- 史料库页的「待接入」自动减少，「已核对」自动增加。
