十一、已知限制（如实记录）

  • 单周目 2—3 小时，走路测试用了「连点继续」的机械策略，不代表真实阅读速度。
  • 走路测试的「步数」会随换场重试与动画时长波动（307—576 步都出现过），只以「115 场景到「名册」、0 错误」为验收口径；2026-10-21 审计快照里的 319 步来自旧一轮，已作废。
  • 3D 帧率以 tools/3d/shots/perf.json 与 test-3d.mjs（App 内 81—148 fps）为准；docs/report/2026-10-22-3d-slices.md 已同步为同一组数字。
  • volume3/volume4 的严格字数低于规划目标（12,816 / 4,148 vs 20,000 / 12,000），属取舍：总量 113,048 已达标，质量审计优先。
  • volume2 的文学评分采用「全量扫描 + 代表场抽读」，未逐场五维重评。
  • 场景插画为本地生成，非历史照片；图片不承担史实表述。
  • 3 个合成结局与交互/3D/音频层在双轨审计冻结后新增，只做人工自查（见 docs/audit/2026-10-22-post-audit-addendum.md）。
