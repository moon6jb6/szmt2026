## 二、参赛打包文件目录（建议）

```
作品名称_作品编号/
├─ 01_作品及成果文件（必含）/
│   ├─ index.html
│   ├─ assets/
│   ├─ art/                   # 场景插画（按 scene id 命名 + 同名参数 JSON）
│   └─ bg/                    # 2.5D 分层的 8 张基准背景图 + 参数 JSON
├─ 02_作品展示视频/            # 按需，可复用评审视频素材
├─ 03_作品介绍文档/
│   └─ 作品介绍.pdf
├─ 04_运行或使用说明/
│   └─ 运行说明.pdf
├─ 05_补充成果材料/
│   ├─ screenshots/           # 10 张作品截图
│   ├─ 测试记录.md            # 走路测试 + 六结局测试 + 字数/结构校验
│   ├─ 审计报告/              # FINAL-fact / FINAL-literary 等
│   └─ 美术报告/              # visual-bible、manifest 说明、质检报告
├─ 06_第三方资源说明/
│   └─ 第三方资源说明.pdf
└─ 07_AI 工具使用补充说明/
    └─ AI使用说明.pdf
```

## 三、匿名化检查

- [ ] 截图、视频、PDF、PPT 内不出现学校、姓名、指导教师

- [ ] 承诺书、学籍材料走身份审核渠道，不混入专家评审材料
