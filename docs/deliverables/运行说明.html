运行与使用说明

〇、先看这里：不能双击 index.html

本作品是 ES Module 静态站点，必须用本地 HTTP 服务打开，不能直接双击 index.html。

双击后会看到：标签页标题正常（「把名字留下来 · 四行仓库一九三七」），页面却是一片全白，地址栏是 file:///…/index.html。按 F12 打开控制台，能看到 … from origin 'null' has been blocked by CORS policy。这不是作品坏了，也不是文件缺失——浏览器在 file:// 下不允许加载 ES Module。换成 HTTP 打开即可。

Windows 两行命令（「命令提示符」或 PowerShell 均可，整段复制）：

pushd "D:\解压位置\把名字留下来_四行仓库·苏州河北岸的四百余个名字_460737\01_作品及成果文件"
python -m http.server 8080

浏览器打开 <http://127.0.0.1:8080/>（开头必须是 http://，不能是 file://）。打开正确的话，2—3 秒内会出现「把名字留下来」标题和「从头开始」按钮。

  • 把 D:\解压位置 换成你实际解压的位置，引号保留（路径含中文、·、括号时没有引号会报「系统找不到指定的路径」）。
  • 先解压再打开：不要在压缩包预览窗口（Windows 自带 zip、7-Zip、WinRAR）里直接双击 index.html，那用的是临时目录和 file://，同样白屏。
  • 手打路径容易错：在资源管理器打开 01_作品及成果文件 文件夹，地址栏清空后输入 cmd 回车，命令行会直接停在该目录，这时只跑第二行就行。
  • python 报「不是内部或外部命令」或弹出微软商店：改用 py -3 -m http.server 8080。
  • 没有 Python：见 §二 方式 A 的 Node 写法；端口被占：换 8081，地址同步改成 http://127.0.0.1:8081/。

二、评审期快速启动（推荐）

方式 A：本地静态服务器（最稳，推荐）

做法与 §〇 相同，这里补上 Node / PHP 两种备选，以及在 Windows 上常撞的几个坑。

① 先进入目录（三种方式共用这一行，路径换成你的实际解压位置）：

pushd "D:\解压位置\把名字留下来_四行仓库·苏州河北岸的四百余个名字_460737\01_作品及成果文件"

② 再任选一种起服务：

A-1 · Python（多数电脑可用，不需要联网）

python -m http.server 8080

A-2 · Node.js（没装 Python 时用）

npx --yes serve -l 8080
  • npx 第一次会联网下载 serve；完全断网且之前没下载过时会失败，那就用 A-1。
  • PowerShell 报「无法加载文件 …\npx.ps1，因为在此系统上禁止运行脚本」：改成 npx.cmd --yes serve -l 8080。

A-3 · PHP（可选）

php -S 127.0.0.1:8080

③ 浏览器打开 <http://127.0.0.1:8080/>。地址栏出现 file:// 就是没走对：要么服务没起来，要么是直接双击了文件。

打包说明：构建已改成相对路径（base: './'），所以整个 01_作品及成果文件/ 目录放在任意子目录下都行。但地址要跟着目录走：如果在上一级 把名字留下来_…_460737/ 起服务，就要访问 http://127.0.0.1:8080/01_作品及成果文件/；此时打开 http://127.0.0.1:8080/ 只会看到一个文件列表，那不是作品页面。

方式 B：源码开发模式（仅开发用，评审不需要这一节）

npm install
npm run dev        # 开发预览
npm run build      # 产出 dist/
npm run preview    # 预览构建产物

九、常见问题

Q：双击 index.html，打开是白屏？
A：正常现象，不是作品坏了。file:// 下浏览器不允许加载 ES Module，控制台会报 origin 'null' … has been blocked by CORS policy。按 §〇 起本地服务器，用 http://127.0.0.1:8080/ 打开即可。如果 HTTP 下仍然白屏，再确认两件事：浏览器没禁用 JavaScript；服务日志里 GET /assets/… 是 200 而不是 404（404 通常是在错误的目录起了服务，见下一条）。

Q：打开 http://127.0.0.1:8080/ 只看到一个文件列表？
A：服务起在了上一级目录。要么改访问 http://127.0.0.1:8080/01_作品及成果文件/，要么按 §〇 进入 01_作品及成果文件/ 再起服务。

Q：提示端口被占用（[WinError 10048] / EADDRINUSE）？
A：8080 被别的程序占了。换端口重跑，例如 python -m http.server 8081，浏览器地址同步改成 http://127.0.0.1:8081/。

Q：PowerShell 报「无法加载文件 …\npx.ps1，因为在此系统上禁止运行脚本」？
A：这是 PowerShell 的执行策略，不是作品问题。把命令换成 npx.cmd --yes serve -l 8080，或先执行 Set-ExecutionPolicy -Scope Process RemoteSigned 再重试；也可以直接用 Python 那条命令（不受执行策略影响）。

Q：敲 python 弹出微软商店，或提示「不是内部或外部命令」？
A：说明这台机器没装 Python（Windows 自带的是个占位跳转）。改用 py -3 -m http.server 8080，或走 Node 的 npx，或 PHP。

Q：路径里有中文、·、括号或空格，命令报「系统找不到指定的路径」？
A：路径必须用英文双引号包住（§〇 的示例已经包住，照抄即可）。更省事的办法：在资源管理器里进入 01_作品及成果文件 文件夹，地址栏清空后输入 cmd 回车，命令行直接停在该目录，不用手打路径。

Q：结局页为什么先黑一下？
A：那是结局的「终极画面」（约 6 秒，Canvas 绘制）。点画面任意位置就能跳过，直接进结局正文。结局正文下面有「重看结局画面」按钮。系统开了「减少动态效果」时只显示最终帧。

Q：九个结局怎么解锁？
A：尾声只会列出你这一周目真正带出来的记忆。六个主结局对应六种载体；如果同时带走两样（名册+口述 / 家书+照片 / 旗样+口信），会额外出现合成结局「档案 / 遗物 / 口耳」。图鉴里 9 格，未解锁的会显示解锁条件。

Q：没有声音？
A：默认静音，点右下角「声音」才开，状态会记住。这一版只有 28 条环境音与动作音（4.88 MB），没有人声配音，也没有音乐。这是取舍，不是坏了。

Q：背景图是渐变不是照片？
A：如果拿到的是「无图版」，说明插画素材没有随包分发。渐变占位版也能完整玩完，叙事与结局不受影响。完整包里才有 public/art/ 下的场景插画。

Q：如何只看结局？
A：菜单 →「结局一览」，已解锁的结局会显示标题与副标题。
