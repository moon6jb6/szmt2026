# 3D 切片报告（2026-10-22）

> 目标：在 2.5D 基底上，为少数关键场景提供**真 3D 背景**；失败自动回退，不阻塞阅读。
> 依赖：three.js 0.186（MIT），按需 lazy 加载（独立 chunk，gzip ≈ 151 KB，主包不变）。

## 三、集成方式

- `src/game/content/scene3d.ts`：场景 id → 切片映射（10 个场景）。
- `src/game/components/Scene3D.tsx`：plain three，组件卸载时 dispose 全部 geometry/material/texture/renderer；`ResizeObserver` 处理尺寸；DPR 上限 2。
- 场景页右上角出现「3D 视角」按钮（仅当：有切片 + WebGL 可用 + 未开减少动效 + 窗口 ≥700px）。
- 打开后：2.5D 分层淡出 600ms，3D 背景透出，正文卡片变为半透明（`backdrop-filter: blur(7px)`），保持可读。
- 相机：指针驱动 yaw ±18°、pitch ±14°、阻尼 0.08；滚轮不劫持。

## 四、回退与无障碍

- 无 WebGL / `prefers-reduced-motion` / 窗口宽度 <700px → 不渲染 3D，也不显示按钮，继续 2.5D。
- 换场景自动回到 2.5D（避免下一场停在 3D 背景）。
- 3D 容器 `aria-hidden`，不进入读屏顺序；不影响键盘操作与存档。

## 六、取舍

- 不做全项目 3D 化（UI 卡片、角色移动、相机全部重写，2 天不可控）；真 3D 只做 4 个 hero 场景。
- 程序化几何做 4 个切片（可复现、无二进制资产）；西墙外观用 Blender 无头建模导出 GLB（4,732 tris / 469.6 KB），按需加载，补上"建筑体量"的真 3D 资产。
- 本地已有 Blender（Store 版）但被 WindowsApps ACL 锁住，另下载便携版 4.2.3 备用于后续 hero 资产精修；本轮未用（程序化切片已达标）。
