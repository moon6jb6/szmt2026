## 2. 必修项（P1，逐条改法）

### C1-P1-1　night3「旗」：段落时序错乱（最严重）

快照段落顺序（正文）：
> ①旗升到杆顶 → ②南岸先静了一下 → ③有人脱帽。有人哭 → ④日本人开始打炮 → ⑤他蹲在楼梯间记东西 → ⑥楼上扔空弹壳 → ⑦递绳子绑旗角 → ⑧记完最后一笔，铅笔掉了 → ⑨楼下传话：把旗杆绑牢 → ⑩**「那一天，仓库里的枪声和南岸的哭声混在一起，分不清谁在哭什么。」** → ⑪**「旗升到一半，绳子卡住了。」** → ⑫旗影投在楼顶水泥地上

- **问题**：① 已「升到杆顶」，⑪ 又「升到一半」——中间没有倒叙标记，读者会以为旗掉下来了。⑩ 是 r0 已判过的抒情总结句，插在动作链中间更显突兀。编号 ⑪ 应移到 ① 之前。
- **改法**：
  1. 把 ⑪「旗升到一半，绳子卡住了。有人用枪托把竹竿往上顶了顶，旗又上去一截。」移到 ① 之前（紧接「旗杆是两根长竹竿接起来的」一段）。
  2. 删 ⑩「那一天，仓库里的枪声和南岸的哭声混在一起，分不清谁在哭什么。」
  3. ⑦⑨ 都写「绑旗/绑旗杆」，合并成一处。
- 修完后 night3 应为 5.0 级——它的旗意象是全书最好的：旗角补丁、旗绳的麻味、竹屑落一地、旗影一格一格往西移。

### C1-P1-2　night3b「墙洞」：三连排比 + 口号 + 格言（三处旧毛病未清）

| 原句 | 问题 | 改法 |
|---|---|---|
| 「他们用沙袋、用棉被、用拆下来的门板。」 | §2.5 三连排比（r0 已判，未改） | 「他们先把沙袋垒到腰高，上面压棉被。门板最后用，四块，拆的是二楼那扇。」 |
| 「陈望生说：「人在，册子在。」」 | 口号式对句（r0 已判，未改） | 删台词。只写动作：「他把册子往那人的绷带里又塞了塞，塞严实。那人疼得抽了口气，点了点头。」 |
| 「册子塞进墙里，就再也拿不出来。**墙是死的，册子是活的。**」 | 格言腔 / 解释性旁白 | 删第二句。留「册子塞进墙里，就再也拿不出来。」——后面「他把册子重新包了一层油纸，从咸菜罐上撕的」已经说明一切。 |

### C1-P1-3　night5「桥」：预叙 + 资料块（r0 C-P0-7 的同型复发）

> 「**后来陈望生才知道：**命令是最高当局下的；上海警备司令杨虎先派人来通知，谢晋元不肯走；最后八十八师参谋长张柏亭亲自来劝，说明这是蒋介石的命令，谢晋元才点了头。」

- **问题**：r0 同段已被判 P0（当时是「后来你才知道」），writer-b 把人称改了、考据补得更全，但**句式没变**。撤退令来源的争议属于史料卡，不属于人物当下能感知的东西。
- **改法**：
  > 命令是晚上九点多到的。一张纸，折成三折，边上有水渍。传令的人念完就走，没说是谁批的。谢晋元没有立刻动。过了一会儿，八十八师参谋长张柏亭亲自来了一趟，两个人在柱子后面说了几句话。说完，谢晋元才转身，让人去通知各连。
  （考据细节移入 aside 或史料卡。）

### C1-P1-4　epilogue「一个盒子」：段落顺序乱 + 窗外三连

快照段落：
> ⑨「窗外雪停了。屋檐上滴下来的水，落在石阶上，一滴一个印。」
> ⑬「他提起笔。**窗外，通城的冬天很安静，听不见枪声。**」
> ⑭「窗外有人在扫雪。扫帚刮过石板，一下，一下。」
> ⑯「《抗战史料》的稿匣只有一个。」
> ⑳「参议员把章盖上。章歪了，红印压住了半个名字。」
> ㉑「参议员把纸按平。纸角还翘着，他用茶杯压住。」
> ㉒「陈望生把笔搁下，右手在膝盖上停了停，等抖过去。」

- **问题 1**：三个「窗外」连用（⑨⑬⑭），第三个是 r0 已判的抒情句，未删。
- **问题 2**：动作链乱——「他提起笔」→「把册子推过去」→「李参议员把笔递回来」→「把余墨刮进小瓷瓶」→「章盖上」→「纸按平」→「把笔搁下」。提笔之后又递笔、盖章之后又搁笔，读不出交接的先后。
- **改法**：
  1. 删 ⑬「窗外，通城的冬天很安静，听不见枪声。」保留 ⑭ 扫帚声（那是全篇最好的收尾音）。
  2. 重排动作链为：**推册子 → 参议员盖章 → 章歪了，红印压住半个名字 → 参议员用茶杯压纸角 → 陈望生把笔搁下，手在膝盖上停一停，等抖过去 → 窗外扫帚声**。
  3. 「《抗战史料》的稿匣只有一个。」这句是全章的收束金句，应放在最后一段之前（现在夹在中段）。

### C1-P1-5　night1 / night1b：百科开场 + 预叙

| 位置 | 原句 | 改法 |

## 3. 加分项（写作者请保持）

1. **谢晋元处理全部升级为动作**（r0 P0 已修）：
   > 「说到「名册」，他伸手在文件箱的盖子上按了一下。墙上那盏煤油灯把他的手影投到柱子上，影子动了一下，墙皮上掉下一点灰。」
   > 「陈望生经过的时候，谢晋元看了他胸前一眼，抬手往下一压。」
   零台词、零虚构引语，比 r0 的「册子，带走」高级得多。
2. **night4 雷雄**（真实人物）：转述 + 动作（「雷雄没答」「雷雄没拦」），没有一句自编台词。处理正确。
3. **night4 铅笔**：「他握着一支铅笔。铅笔很轻。可他举不起来。」——r0 保留，位置也对。
4. **night5b「雾」4.7，全章最佳**：
   > 「点到陈望生的时候，他报完名字。他听见自己的声音，很平，像在报别人的名字。」
   > 「路边有一个卖豆浆的摊子，锅还热着。摊主把锅盖盖上，转过身去。」
5. **night4b 物资三递进**：饼干落水 → 竹竿差两米 → 上游漂来木盆装两罐药（罐口蜡封、纸上写「白药，止血用」，笔画很细）。这是扩写的正确方式：不是加形容词，是加**事件层级**。
6. **epilogue 掉出来的四样东西**：半张报纸、一块被面的红、一根断了头的铅笔、一张十一个人的合影——把六个结局的记忆载体全部前置于一个动作，结构上很漂亮。
