## 2. 三个偏差（按优先级）

### A. 节奏单一化（最普遍，四卷全中）

**症状**：句子长度集中 15—21 字，几乎每句都带 1—2 个逗号（逗号密度 7.7—9.0/百字）。
段落从第一句到最后一句是**同一个速度**，没有加速、没有停顿、没有断裂。

**为什么是问题**：规划 §2.2「句子偏短」不是要求每句都短，是要求**有断裂**。人写小说靠短句变速：紧张时 3—5 字一句，铺陈时 20 字一句。全程匀速 = 读者失去节拍感 = AI 味最强的信号（`humanize-chinese` 的短句占比 d=1.21 是最强单信号）。

**改法（硬规则，写作者请照做）**：
1. 每场至少 **3 个「断」**：找到一个发现、一次转身、一句不想说出口的话，用一个 ≤8 字的句子砸下去，然后换段。
2. 段落**最后一句常常应该是最短的**；不要用 20 字的完整句收尾。
3. 不要连用三个「逗号 + 分句」。三个逗号以上，砍成两句。

**示范**（volume3 v3-04 现场改写，只动断句）：
> 原：谢晋元写完一页，吹了吹墨，才把册子拿过去。他翻到通城那几页，一页一页看。看到空着的那一格，手指在纸上按了一下，按了很久。
> 改：谢晋元写完一页，吹了吹墨，才把册子拿过去。翻到通城那几页。一页一页看。看到空着的那一格，手指按下去。很久没抬。

## 4. 三条自检规则（写完每一场跑一遍）

```bash
node docs/audit/tools/lit-scan.mjs src/game/content/volumeX.ts
```

1. **短句 ≤10 字 占比 <20%** → 加断句，每场至少 3 处。
2. **出现「旁白[后来这些/很多年后/他也不知道为什么/他想，要是]」** → 逐条删或换成年份/动作。
3. **出现「第二人称」** → 确认是否在人物对话里；若在叙述里，改成「他／陈望生」。
4. 附带看：具体物密度 <5/百字 → 这一场在靠概述撑；句长 CV <0.35 → 节奏太平。

> 扫描器的禁区：它数不出来「好不好」。数字只用来找嫌疑，最终判断要人读。误报要人工排除。
