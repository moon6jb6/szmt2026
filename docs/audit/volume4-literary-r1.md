## 2. 必改项

### V4-P1-1　体量不足：15 场 4,254 字（均 284 字/场），目标是 12,000 字

- **问题**：现在的每一场都是一篇「微型小说」——起承转合俱全，但都只有 8 段。作为「结局后读者页」，读起来像目录而不是场景。对比：volume0 平均 909 字/场，volume3 平均 511 字/场，volume5 平均 1,014 字/篇。
- **改法**：**不要靠加形容词扩写，靠加「动作链」**。每场补 3—5 段「当下正在做的事」，规则：
  1. 开头补一个「进场的动作」（谁推的门、手上拿着什么、脚下踩到什么）；
  2. 中段补一个「意外的物」（不该出现的、坏了的、掉了的、别人塞的）；
  3. 结尾不要动（15 个结尾全部合格，一个都不要改）。
- 优先级：v4-03 / v4-09 / v4-10 最薄（各 200 字上下），先补这三场。

### V4-P1-2　与 endings.ts 素材重复（三处）

| 素材 | endings | volume4 | 问题 |
|---|---|---|---|
| 录音带 A-017 | testimony 结局（约 1,600 字，含「7 的横划拖得很长」「这个能存多少年」） | v4-04（约 300 字，**同样两句原话**） | 逐句重复 |
| 周福其跪谢晋元铜像 | testimony 结局 | v4-08（陈念生视角） | 事件重复，细节重复（膝盖响、手掌擦出干净地方） |
| 英名墙 323→354 / 88D | roster 结局、photo 结局 | v4-11、v4-14 | 数字与展陈描述重复 |

- **问题**：读者先看结局、后看卷四时，会产生「刚才不是看过了」的感觉。两个文件承担不同功能：**结局回答「哪种记忆被留下」；卷四回答「名字之后，东西在谁手里」**。同一个事件可以用，但必须**换信息**。
- **改法**（保留卷四，改造重复处）：
  - v4-04：不写录音过程（结局已写），只写**磁带盒在木盒里躺在哪一格**——「磁带盒比册子短一寸，垫在底下，拿册子的时候会先碰到它」。
  - v4-08：不写跪的动作（结局与 v5-09 已写两次），只写**陈念生没上前的那两步**——「他想上前扶一把，脚迈出去，又收回来。老人自己撑着地站起来」——这一句是全场最好的，把其他动作细节删掉，只留这句。
  - v4-11 / v4-14：不重复数字考据，改写成「墙上那一排空白胸标」的物理细节（比如「空胸标里积了灰，擦玻璃的人擦不到那一格」）。

## 3. 加分项（写作者请保持）

1. **v4-06「木盒」5.0**：
   > 「陈念生一样一样看。他把册子翻开，翻到最后，问：「爷爷，这里头有没有你的名字？」」
   > 「陈望生说：「没有。」」
   > 「「为什么没有？」」
   > 「陈望生把册子拿回去，一页一页捋平，捋到中间那一页，停住。他没有答这句话，只说：「你记住这些纸放在哪里。别丢。」」
   全书「不直呼情绪」的最高示范：一个「没有」＋一句「别丢」，把整部小说的重量压进去了。
2. **v4-15「留白」5.0**：
   > 「他捏着那张纸——是前一天的收据，背面白的。他用圆珠笔在纸背写下爷爷的名字，写完，折了两折，捏在手里。」
   > 「石匠问：「你家有名字要刻？」」
   > 「陈念生看着那排空白石板，说：「再等等。」」
   「再等等」三个字是全书最好的结尾之一。**不要扩写这一段，保持原样。**
3. **v4-02「墙洞」**：「他拍打布面上的灰，拍到第三下，停住了，把布包放在膝盖上，坐了很久。灶膛里的灰还是温的。」——动作到第三下才停，是节奏感。
4. **v4-05「广播里的歌」**：「陈望生没有哼。他攥着锄头把，手指在木柄上一下一下地敲，敲到那一句，敲对了拍子。」——歌在耳朵里，手在锄头上，这是「用身体记住」，不是用脑子。
5. **v4-13「看电影」**：「散场出来，儿子问：「爷爷真的在里面？」「在。」「那他名字怎么不在墙上？」陈念生没有立刻答。电影院的灯全亮了，地上都是爆米花纸筒。他说：「回家再说。」」——用爆米花纸筒隔开那句答不出的问题。
6. **全卷零 P0**：禁用词 0 / 旁白 0 / 第二人称 0 / 三连 0 / 大词 0。真实人物（丁老师、定老师、姓沈的调查者、周福其）全部转述、无虚构台词。
