# 图片人工抽查记录（art-director）

> 规则：image-runner 每批 50 张，art-director 抽 10 张（20%），逐张按「灵魂五问」＋硬红线判定。
> 图源：image-runner 生成目录 `D:/AI大模型/art-work/`（QA 通过后由 Lead 回拷 `public/art/`）；本记录的 id 与 `docs/art/image-manifest.json` 一一对应。
> 判定：**A** = 有灵魂，可做节点头图；**B** = 合格背景；**C** = 可用但只有氛围（建议降级/换 seed）；**R** = 硬伤 reject（人脸/文字/现代物/旗帜图案/暴行/年代错）。

## 0. 灵魂五问（每张逐条）

1. **有没有一个具体物**？（不是"仓库一角"，而是"半块干粮""缝过的衣襟""一把钥匙"）
2. **有没有一道光在替我们看**？（光落在哪个物上，是不是那束光在讲故事）
3. **有没有人的缺席**？（空椅、没写完的册、墙上的影子、桥头的空位）
4. **删掉氛围之后还剩什么动作**？（只剩"好看"＝空镜，C）
5. **放进 500 张里能不能被认出来**？（不重复、不壁纸、不油腻）

≥3 个"是"＝通过；全部"是"＝A。硬红线（人脸/可读文字/现代物/旗帜图案/暴行/年代错）一票 R。

抽样策略：每批 10 张 = 按类别配额均匀取 ＋ 优先抽"高风险 prompt"（有人物动作暗示、近景、文物带字、旗帜相关、年代跨度大如 1947/1982/2005/2025）。

## 1. 第一轮抽查（r1 冒烟，2026-10-21 00:47—00:49，3 张）

| id | 场景 | 判定 | 五问命中 | 说明 |
|---|---|---|---|---|
| scene-001 | v0-01 1947 县参议会厢房，纸笔与空桌 | A- / pass | 物（纸/砚/笔）✓ 光（窗光斜入）✓ 缺席（空椅）✓ 动作（"推过桌面"的余温）△ 辨识度 ✓ | 要素齐、可放 UI；但偏暗偏冷，与 `public/bg` 基准暖调有差 |
| scene-002 | v0-02 左襟夹层里的册子 | **R** | — | 生成了清晰年轻男性正脸＋上半身，硬红线（清晰人脸） |
| scene-003 | v0-03 雪后通城县街，一行脚印 | **R** | — | 画面出现 6—7 个行走人影，硬红线（scene 类不许有人）；年代服饰偏古装 |

**结论：判 r1 prompt 体系性失败，不是单 seed 问题。**
根因两条：
1. `gen.py` 在 `guidance=0`（Lightning 4-step 默认）时**不把 negative 传给 pipeline**，红线段全部失效；
2. `no people` 放在 prompt 最末尾，CLIP 权重最低，且"衣襟/脚印/街"这类词本身就在暗示人。

**修复（manifest r2 → r3 → r4）**：① 风格前缀后**紧跟类别护栏**（`empty scene, no people, no faces, no text` 等，前置权重高）；② 风格前缀加 `warm sepia` 对齐 public/bg 暖调；③ 裁剪策略改为"先删构图段/纯光线段、保具体物"，并把估算校准到真实 tokenizer（估 ≤66 / 真实 ≤72）；④ **r4：writers 交齐 128 场后，scene 类 prompt 全部按真实场景表重写**（不再用我按计划猜的画面），非 1937—1941 的 26 张用时代中性前缀。id/seed/配额不变。
**r1 图处理**：作废，移入 `rejected/` 或忽略；正式计数从 r4 开始。
